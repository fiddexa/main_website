# FIDDEXA website update

This package is a clean redesign based on the requested business-card style:
- white background
- dark navy accent
- thin rules
- restrained typography
- no gold gradients
- no glassmorphism
- simple B2B navigation
- responsive mobile layout

Files:
- index.html
- about.html
- offers.html
- partner.html
- style.css
- script.js

Existing repository images are intentionally referenced:
- images/fiddexa-title.png
- images/hero.png

IMPORTANT:
partner.html contains a placeholder `YOUR_WEB3FORMS_ACCESS_KEY`.
Replace it with the existing Web3Forms access key before publishing.
